YTM Practice Grabber

Lyrics files and audio from YouTube Music, named alike, for practising with Tony.

Lyrics capture

When to capture

Chrome's debugger is attached to the tab only for the few seconds after you click the lyrics button, while Better Lyrics loads the song's lyrics again. Meanwhile Chrome shows a bar saying that “YTM Practice Grabber” started debugging this browser.

The debugger stays attached to every YouTube Music tab and keeps whatever lyrics Better Lyrics loads, so a click needs no extra request. Chrome's debugging bar stays up the whole time (starting Chrome with --silent-debugger-extension-api hides it).

Writes each capture's steps (which way the lyrics response was read) to the service worker's console. Never the request or the lyrics.

Downloads

Saves a song's files in a folder named like them: lyrics in <song>\ in Chrome's download folder, audio in <song>\ in the audio folder below. Handy with Tony, whose Import Lyrics dialog opens in the audio's folder.
